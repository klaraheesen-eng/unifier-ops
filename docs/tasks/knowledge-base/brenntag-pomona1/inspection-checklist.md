# Unifier Inspection Checklist

Prepared for: Brenntag contractor onboarding (Pomona1)

## Purpose
Provide a reusable branded inspection checklist template for Unifier site work and contractor pack submissions.

## Sections Included
1. General Site Readiness
2. PPE and Personnel
3. Tools, Equipment and Vehicles
4. Work Execution and Controls
5. Environmental and Close-Out
6. Inspector Notes / Corrective Actions

## Files
- `docs/tasks/source-docs/brenntag-pomona1/unifier-inspection-checklist.png`
- `docs/tasks/source-docs/brenntag-pomona1/unifier-inspection-checklist.pdf`
- `scripts/render_inspection_checklist.py`

## Template Notes
- Branded with the Unifier logo.
- Includes header fields for project/site, date, inspector, and supervisor.
- Each checklist line provides Yes / No tick boxes and a comments/action area.
- Suitable as a general pre-start / site inspection checklist for Brenntag submission unless a more site-specific checklist is later requested.
