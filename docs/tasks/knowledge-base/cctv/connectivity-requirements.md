# CCTV connectivity requirements

## Core requirement
All CCTV installations require a network cable connection to a router or equivalent network device.

## Preferred connection
- Fibre is the first-choice recommendation because it provides the most stable connection.

## Secondary router options
- LTE router
- WiFi router with 4G or 5G connectivity

## Example providers
- Rain
- Vodacom

## Notes
Use this as a standard client-facing requirement when confirming site readiness for CCTV installations. Recommend fibre first, and present LTE or 4G/5G router options as secondary alternatives.
